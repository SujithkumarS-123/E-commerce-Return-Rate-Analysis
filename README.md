# E-commerce Return Rate Reduction Analysis

## Project Overview

This project analyzes e-commerce product returns to identify the major factors affecting return rates and help reduce product returns.

The analysis was performed using Python, SQL and Power BI.

## Objectives

- Analyze overall product return rates
- Identify categories with high return rates
- Analyze return patterns by location, gender and discount
- Identify factors associated with product returns
- Predict high-risk return orders
- Create an interactive Power BI dashboard
- Generate a list of high-risk products

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- SQL / MySQL
- Power BI
- Excel / CSV

## Key Analysis

The project analyzes:

- Return Rate
- Return Cost
- Return Reasons
- Product Category
- Product Price
- Discount
- Order Quantity
- Customer Age
- Customer Gender
- Location
- Shipping Method
